This folder is intentionally empty.

All music and sound effects in RealmForge II are synthesised in the browser
with the Web Audio API (js/audio.js): the regional themes are built from a
scale and a chord walk, and effects like chopping, mining and spellcasting are
made from short oscillator and filtered-noise bursts.

Nothing is sampled from any other game. If you would rather ship real audio
files, put them here and adapt js/audio.js to load them.
