REALMFORGE II UI ASSET PACK v0.1

Purpose:
Replace plain browser/HTML-looking UI with a cohesive old-school fantasy MMO interface.

Style target:
- classic RuneScape/RS2 readability
- HD-ish remaster, not pixel-art
- dark wood/stone/bronze palette
- warm gold borders
- readable at 1080p
- restrained ornamentation
- no glossy mobile-game look

Included:
- 4x7 inventory frame
- reusable inventory slot states
- minimap frame
- chat frame
- side panel
- small/medium/large button states
- 9 UI tab backgrounds with icons and states
- health/prayer/run/mana orbs
- tooltip/context menu
- parchment world-map background and frame
- map markers
- basic resource/skill icons
- HUD layout reference

IMPLEMENTATION:
Do not redraw these in CSS except for text overlays and layout.
Use the PNGs directly. Preserve aspect ratio.
Recommended:
- inventory item icons 32-36px inside 42px slots
- tabs 46x46
- map markers 24-32px
- minimap content masked inside the supplied circular frame
- use a readable serif/fantasy font for headings and a clean bitmap-like sans-serif for body text.
